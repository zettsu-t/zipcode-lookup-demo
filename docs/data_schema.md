# はがき配布サービス — データスキーマ定義

## 1. アプリケーションデータ（Django管理）

### Sender（差出人）

1アプリにつき1レコード。

| フィールド | 型 | 制約 | 備考 |
|-----------|-----|------|------|
| id | integer | PK, auto | |
| names | JSONField | NOT NULL | 連名リスト。例：`["山田 太郎", "山田 花子"]`。件数制限なし。 |
| zipcode | varchar(8) | NOT NULL | ハイフンあり形式で保存（例：`231-0045`） |
| address | varchar(400) | NOT NULL | 郵便番号補完後も手動編集可能 |
| created_at | datetime | NOT NULL | |
| updated_at | datetime | NOT NULL | |

### Guest（出席者）

1アプリにつき0件以上。

| フィールド | 型 | 制約 | 備考 |
|-----------|-----|------|------|
| id | integer | PK, auto | |
| names | JSONField | NOT NULL | 連名リスト。1項目以上5項目以下。例：`["山田 太郎", "山田 花子"]` |
| zipcode | varchar(8) | NULLABLE | ハイフンあり形式。任意入力 |
| address | varchar(400) | NULLABLE | |
| created_at | datetime | NOT NULL | |
| updated_at | datetime | NOT NULL | |

## 2. 郵便番号データ（FastAPI管理）

アプリには同梱しない。運用時に別途ダウンロードして組み込む。

### ken_all.csv（一般住所）

日本郵便配布。約12万件。文字コード：UTF-8。列名なし。

| 列（0-indexed） | 内容 | 使用 |
|----------------|------|------|
| 2 | 郵便番号（7桁、ハイフンなし） | ○ |
| 6 | 都道府県名（漢字） | ○ |
| 7 | 市区町村名（漢字） | ○ |
| 8 | 町域名（漢字） | ○ |
| その他 | 読み仮名、フラグ等 | — |

検索用フルアドレス = 列6 + 列7 + 列8

## 3. 既知のデータ品質問題

ken_all.csv に存在する問題。テスト設計で考慮が必要。

| 問題 | 具体例 | 対処方針 |
|------|--------|---------|
| 同一住所に複数郵便番号 | 大企業本社ビル | 複数返却を仕様とする |
| 町域名の分割レコード | 長い町名が2行に分割 | 読み込み時に結合する |
| 読み方の揺れ | 「ケ」「ヶ」「が」 | 現時点では正規化しない（将来検討） |
| 地名の重複 | 「京橋」は東京・大阪・広島等に存在 | 複数返却を仕様とする |

## 4. zipcode フォーマット規約

本サービスでは郵便番号をハイフンあり形式（`NNN-NNNN`）で統一する。

| レイヤー | フォーマット | 備考 |
|---------|------------|------|
| Django（保存・表示） | `NNN-NNNN` | |
| FastAPI（CSV読み込み） | 7桁ハイフンなし → ハイフンあり形式に変換して返す | |
| 相互変換 | `"1234567"` ↔ `"123-4567"` | |
