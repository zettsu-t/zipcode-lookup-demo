# はがき配布サービス — API契約

DjangoフロントエンドとFastAPIバックエンドの境界を定義する。
この契約を変更する場合は、両側を同時に更新しなければならない。

---

## 1. 共通仕様

- ベースURL：`http://backend:8001`（環境変数 `BACKEND_URL` で上書き可能）
- レスポンス形式：JSON
- 文字コード：UTF-8
- 郵便番号フォーマット：ハイフンあり（例：`231-0017`）

---

## 2. エンドポイント

### GET /api/v1/zip — 郵便番号→住所の順引き（stage 1）

**リクエスト**

| パラメータ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| `code` | string | ○ | 郵便番号。ハイフンあり・なし両方を受け付ける |

```
GET /api/v1/zip?code=2310017
GET /api/v1/zip?code=231-0017
```

**レスポンス 200 OK**

```json
{
  "zipcode": "231-0017",
  "address": "神奈川県横浜市中区港町"
}
```

郵便番号が一意に確定できる範囲で住所を返す。該当なしの場合は404。

**レスポンス 404 Not Found**

```json
{
  "detail": "zipcode not found"
}
```

**レスポンス 400 Bad Request**

```json
{
  "detail": "invalid zipcode format"
}
```

---

### GET /api/v2/address — 住所→郵便番号の逆引き（stage 2）

**リクエスト**

| パラメータ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| `q` | string | ○ | 検索クエリ。2文字以上。ワイルドカード`*`使用可 |

```
GET /api/v2/address?q=横浜市中区
GET /api/v2/address?q=神奈川県庁
GET /api/v2/address?q=京*橋
```

**レスポンス 200 OK**

```json
[
  {
    "zipcode": "231-0017",
    "address": "神奈川県横浜市中区港町",
    "type": "general"
  },
  {
    "zipcode": "231-8588",
    "address": "神奈川県庁",
    "type": "jigyosho"
  }
]
```

| フィールド | 説明 |
|-----------|------|
| `zipcode` | ハイフンあり形式 |
| `address` | 表示用フルアドレス |
| `type` | `"general"`（ken_all.csv）または `"jigyosho"`（JIGYOSYO.CSV） |

結果の順序：`jigyosho` を `general` より先に返す。

**レスポンス 400 Bad Request**

```json
{
  "detail": "query too short"
}
```

クエリが1文字以下の場合。

---

## 3. 制約と禁止事項

| 項目 | 内容 |
|------|------|
| 正規表現入力 | 禁止。`*` と `?` のワイルドカードのみ許可（ReDOS対策） |
| クエリ最小長 | 2文字以上。1文字以下は400を返す |
| レスポンス件数上限 | 未定義（将来必要なら追加する） |
| 認証 | なし |
| HTTPS | デモ環境ではHTTPを許容する |

---

## 4. DjangoからFastAPIを呼ぶ責任範囲

Djangoが知っていいこと：

- エンドポイントのURLとパラメータ名
- レスポンスのJSONフィールド名と型
- HTTPステータスコードの意味

Djangoが知ってはいけないこと：

- インデックスの構造（FTS5、dictの詳細）
- CSVのフォーマット
- 検索アルゴリズムの詳細

将来FastAPIの実装をSaaSに置き換えても、Djangoは一切変更しない。

---

## 5. バージョニング方針

- URLパスにバージョンを含める（`/api/v1/`、`/api/v2/`）
- 既存エンドポイントは変更しない（後方互換を保つ）
- 破壊的変更が必要な場合は新バージョンを追加する
