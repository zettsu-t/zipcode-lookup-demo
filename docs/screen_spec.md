# はがき配布サービス — 画面仕様書

画面操作仕様書。実装の根拠・操作ルールを記載する。レイアウトの細部はテンプレートを参照。

---

## 共通レイアウト

### ナビゲーションバー

全画面の上部に常に表示。

| リンク | 遷移先 |
|--------|--------|
| 返礼はがき送付サービス（ブランド名） | `/` |
| 差出人設定 | `/sender/` |
| 出席者リスト | `/guests/` |

---

## 画面一覧

### S-1: 差出人設定

**URL**: `/sender/`
**メソッド**: GET / POST

#### 表示内容

- 差出人が未登録のとき: 「まだ登録されていません」という案内メッセージを表示する
- 差出人が登録済みのとき: 登録済みの値をフォームに表示する

#### フォームフィールド

| フィールド | 入力形式 | 備考 |
|-----------|---------|------|
| 氏名（連名・1行1名） | テキストエリア（3行） | 1行1名、1名以上必須 |
| 郵便番号 | テキスト | 形式: `NNN-NNNN`、最大8文字 |
| 住所 | テキスト | 郵便番号補完対象 |

#### 操作

- **保存**: フォームを送信し、差出人情報を登録・上書き保存する。成功後は同じ画面に戻る。
- **郵便番号からの住所補完**:
  - 郵便番号フィールドでEnterキーを押すと住所が自動補完される
  - 郵便番号フィールドからフォーカスが外れたときも住所が自動補完される
  - 補完後も住所は手動で編集できる

---

### S-2: 出席者リスト

**URL**: `/guests/`
**メソッド**: GET

#### 表示内容

- 出席者が0件のとき: 「出席者が登録されていません」という案内メッセージを表示する
- 出席者が1件以上のとき: 一覧テーブルを表示する

#### テーブル列

| 列 | 内容 |
|----|------|
| # | 通し番号（登録順） |
| 氏名 | 連名は `/` 区切りで表示 |
| 郵便番号 | 未登録の場合は `-` |
| 住所 | 未登録の場合は `-` |
| 操作 | 「編集」「削除」ボタン |

#### 操作

- **出席者を追加**: S-3へ遷移する
- **編集**: 対象出席者のS-4へ遷移する
- **削除**: 対象出席者のS-5へ遷移する

---

### S-3: 出席者追加

**URL**: `/guests/new/`
**メソッド**: GET / POST

#### フォームフィールド

| フィールド | 入力形式 | 備考 |
|-----------|---------|------|
| 氏名（連名・1行1名、最大5名） | テキストエリア（3行） | 1名以上5名以下必須 |
| 郵便番号 | テキスト | 形式: `NNN-NNNN`、最大8文字、任意 |
| 住所 | テキスト | 任意 |

#### 操作

- **追加**: フォームを送信し、出席者を新規登録する。成功後はS-2へ遷移する。
- **キャンセル**: 保存せずS-2へ戻る。
- **郵便番号からの住所補完**: S-1と同じ動作。

---

### S-4: 出席者編集

**URL**: `/guests/<id>/edit/`
**メソッド**: GET / POST

#### 表示内容

登録済みの値をフォームに表示する。フィールド構成はS-3と同じ。

#### 操作

- **編集**: フォームを送信し、出席者情報を上書き保存する。成功後はS-2へ遷移する。
- **キャンセル**: 保存せずS-2へ戻る。
- **郵便番号からの住所補完**: S-1と同じ動作。

---

### S-5: 出席者削除確認

**URL**: `/guests/<id>/delete/`
**メソッド**: GET / POST

#### 表示内容

削除対象の出席者情報（氏名・郵便番号・住所）を表示し、削除を確認する。

#### 操作

- **削除する**: 出席者を削除し、S-2へ遷移する。この操作は取り消せない。
- **キャンセル**: 削除せずS-2へ戻る。
